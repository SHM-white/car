# UDP 协议 v1

## 数据包

所有整数按小端序编码。最大载荷 64 字节，最大数据包 96 字节，不允许把 C/C++ 结构体直接映射到网络缓冲区。

| 偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 2 | 魔数 `0x4454`，线上字节为 `54 44` |
| 2 | 1 | 版本 `1` |
| 3 | 1 | 消息类型 |
| 4 | 2 | 载荷长度 `N`，范围 0..64 |
| 6 | 4 | 发送者 ID |
| 10 | 4 | 随机启动纪元 `boot_id` |
| 14 | 4 | 单调递增序号 |
| 18 | 4 | 发送者启动后的毫秒数，仅供诊断 |
| 22 | N | 载荷 |
| 22+N | 2 | CRC16-CCITT，覆盖头部和载荷 |
| 24+N | 8 | HMAC-SHA256 前 8 字节，覆盖头部、载荷和 CRC |

接收新鲜度只使用本机单调接收时间，不能使用发送方毫秒数。序号前向距离必须位于 `(0, 2^31)`，以支持 `uint32` 回绕并拒绝重复、乱序和重放。

## 消息类型

| 值 | 名称 | 方向 | 载荷 |
| ---: | --- | --- | --- |
| 1 | `HEARTBEAT` | 任意已配置端点 | 空 |
| 2 | `CAR_TELEMETRY` | 车辆 -> ROS/HMI | 17 字节 |
| 3 | `TASK_SELECTION` | HMI -> ROS | 9 字节 |
| 4 | `MISSION_STATUS` | ROS -> HMI | 18 字节 |
| 5 | `DIAGNOSTIC` | ROS -> 车辆，可选 | 由集成方版本化定义 |

### 车辆遥测载荷

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0 | `u8` | 车辆状态：0 就绪、1 运行、2 完成、3 安全停车 |
| 1 | `u8` | 转弯：0 直行、1 小弯、2 大弯 |
| 2 | `u8` | 事件：0 无、1 启动、2 B、3 D、4 A、5 完成 |
| 3 | `u16` | 事件 ID；非零事件按此字段幂等去重 |
| 5 | `u16` | 质量标志 |
| 7 | `i32` | 从起点沿赛道正方向累计位移，毫米 |
| 11 | `i16` | 滤波后的轮速，毫米/秒 |
| 13 | `i16` | 归一化循迹误差乘 1000 |
| 15 | `u16` | 故障标志 |

车辆以 20 Hz 发送该载荷，接收端在 750 ms 后标记为陈旧。同一事件会连续发送 5 帧且保持相同 `event_id`，接收端必须按 ID 幂等处理。B/D/A 只能按照 `START -> B -> D -> A -> COMPLETE` 出现；距离阈值必须用实物赛道标定。

### 任务选择载荷

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0 | `u32` | 选择 ID，重发时保持不变 |
| 4 | `u32` | 当前车辆 `boot_id` |
| 8 | `u8` | 任务编号，只允许 1 或 2 |

### 任务状态载荷

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0 | `u32` | ROS 确认的选择 ID |
| 4 | `u32` | ROS 当前确认的车辆 `boot_id` |
| 8 | `u32` | 本回执所针对的 HMI `boot_id` |
| 12 | `u8` | 阶段：预启动、选择已确认、已获准、车辆运行、完成、故障 |
| 13 | `u8` | 已确认任务，0/1/2 |
| 14 | `u16` | 原因或故障标志 |
| 16 | `u16` | 权威状态标志：bit0 无人机链路、bit1 已解锁、bit2 视觉有效、bit3 ROS 就绪；其余位必须为 0 |

HMI 上电后先用心跳头部公布自己的新 `boot_id`。ROS 返回的所有任务状态必须同时绑定当前车辆和 HMI 启动纪元；不匹配的回执不能开放选择控件。HMI 只能显示 ROS 给出的无人机和视觉状态，不能自行合成健康值。

## 地址与端口所有权

示例地址只用于说明，实际地址必须由热点的 MAC-DHCP 保留表提供。

| 节点 | 示例地址 | 自有 UDP 端口 |
| --- | --- | ---: |
| 空中 ROS | `192.168.20.1` | 42000 |
| 车辆 | `192.168.20.2` | 42001 |
| HMI | `192.168.20.3` | 42002 |

热点必须启用 WPA2，且 AP 客户端隔离策略必须允许“车辆 -> HMI”的显式单播。允许的端点对只有：车辆到 ROS、车辆到 HMI、HMI 到 ROS、ROS 到 HMI，以及可选的 ROS 到车辆诊断；禁止广播。
