# 硬件接线与首次上电检查

## 车辆示例引脚

以下仅对应 `config_local.example.h`，必须与实际原理图核对后写入未跟踪的 `config_local.h`。

| 功能 | 示例 GPIO |
| --- | --- |
| 感为八路灰度传感器 I2C | SDA=1，SCL=2，扫描地址 0x4C~0x4F |
| 左电机 PWM / IN1 / IN2 | 6 / 7 / 8 |
| 右电机 PWM / IN1 / IN2 | 9 / 10 / 11 |
| 左编码器 A / B | 12 / 13 |
| 右编码器 A / B | 14 / 15 |
| 启动按钮 | 16，低电平有效，内部上拉 |

## 架空车轮自检

1. 断开电机电源，确认 ESP32、驱动板、传感器和电平转换器共地。
2. 灰度传感器使用独立、稳定的 5V 供电；不得与电机直接共用未经稳压和滤波的电源。
3. SDA/SCL 必须经过双向 I2C 电平转换：ESP32 侧上拉至 3.3V，传感器侧上拉至 5V。只有在电平转换器高压侧没有上拉时才安装传感器的 SCL/SDA 上拉跳帽。
4. 确认所有 GPIO 都是当前板卡可用引脚，没有连接 Flash/PSRAM 或启动绑带冲突。
5. 上电串口必须出现“感为八路 I2C 已就绪”，并核对扫描出的地址、固件版本和归一化状态。
6. 按传感器手册完成黑场、白场校准；正视安装时，代码会把物理通道 8~1 映射为从左到右。
7. 低占空比测试左右电机方向和制动电平，随后校正编码器符号。
8. 确认按钮按一次只产生一个 `START`，长按超过 3 秒进入 `SAFE_STOP`。
9. 运行中断开传感器 SDA 或 SCL，车辆应立即制动，250 ms 后锁存失线故障。
10. 运行中关闭热点，1 秒后车辆必须制动；热点恢复不得自动继续。
11. 最后再标定 PID、大小弯迟滞阈值及 B/D/A/完成距离。

## 微雪地面站上电检查

地面站型号固定为 `ESP32-S3-Touch-LCD-7`：800x480 ST7262 RGB 屏、GT911 触摸和 CH422G 扩展 IO。显示总线及控制引脚已经由 `ESP32_Display_Panel 1.0.4` 的官方板型定义管理，不要与车辆示例引脚表混用。

1. 只通过板卡允许的 USB/UART 与 5V 接口供电，不要同时从两个来源反向供电。
2. 开发板必须选择 `Waveshare ESP32-S3-Touch-LCD-7`，并选择 PSRAM Enabled、QIO 80MHz、8MB Flash、USB CDC Disabled 和 `Huge APP`。
3. 上电串口应先显示 PSRAM 总容量与可用容量，再依次出现面板初始化、LVGL 初始化和“屏幕与 GT911 已就绪”；任一步失败都应保留串口日志定位。
4. 分别触摸 `TASK 1`、`TASK 2`、确认和取消，确认触摸坐标未镜像且一次触摸只产生一个动作。
5. 断开 ROS 或车辆数据源，750 ms 后顶部数据龄和底部故障条必须显示陈旧；不得继续显示旧位置为健康。
6. 车辆运行或出现故障后，两个任务按钮仍应保持可用；重新选择后由 ROS 回执表明是否接受。
7. 左下角应显示小字 `FPS n`，静置和操作界面时数值都应持续更新且不遮挡故障信息。
8. 动态刷新时画面不得向下漂移；串口应显示 `RGB 回弹缓冲=16000 字节`。
